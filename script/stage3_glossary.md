# Глоссарий этапа 3 (сюжеты Ceres / 79au)

Единый стиль для всех файлов. Литературный русский, консистентно со старым переводом.

## Обращение
- **«ты»** — нарратив от 2-го лица к игроку (описания сцен, «You walk…», «You feel…»). ЭТО ОСНОВНОЙ РЕЖИМ в 79au/ceres — игрок это «ты».
- **«вы»** — реклама, слоганы, формальные объявления.

## Токены-плейсхолдеры — СОХРАНЯТЬ ТОЧНО, не переводить содержимое в скобках
- `[us]`, `[them]`, `[us-subj]`, `[them-subj]`, `[them-pos]`, `[them-obj]` — местоимения, движок подставит.
- `[us-firstname]`, `[us-surname]`, `[us-fullname]`, `[us-shipname]`, `[us-age]`, `[us-homeworld]` — данные игрока.
- **Глагольные токены** `[watches]`, `[hacks]`, `[asks]`, `[uses]`, `[tells]`, `[offers]`, `[introduces]`, `[breaks]`, `[records]`, `[seems]`, `[looks]`, `[checks]`, `[has]`, `[is]` — движок сам склоняет по таблице. ОСТАВЛЯТЬ английский токен в скобках как есть (`[hacks]`), либо, как в старом переводе, можно заменить на русский инфинитив-токен (`[взламывать]`) — оба резолвятся. **Предпочтительно оставлять английский токен** — надёжнее. Строить фразу так, чтобы токен стоял на месте сказуемого: `[us] [hacks] [them]` → `[us] [hacks] [them]` (глагол сам согласуется).
- `[us-gains]`, `[us-hacks]` — составные, оставлять как есть.
- **Гендер-условия**: `[us-custom-characterGenderCond|his|her|their]` → перевести варианты внутри: `[us-custom-characterGenderCond|его|её|их]`. Формат: `[us-custom-characterGenderCond|муж|жен|мн]`. Число вариантов (обычно 3, через `|`) СОХРАНЯТЬ.
  - `|him|her|them|` → `|него|неё|них|` (или по контексту падеж)
  - `|he's|she's|they're|` → `|он|она|они|`
  - `|man|woman|hero|` → по смыслу: `|мужчина|женщина|герой|`
- `\n` — переносы строк, сохранять все.
- HTML-теги `<size=..>`, `<color=..>`, `<b>` — сохранять точно.
